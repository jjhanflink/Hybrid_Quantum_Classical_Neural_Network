# Hybrid Quantum-Classical Neural Network with Local Privacy Sanitization

A production-oriented benchmark and implementation of a Hybrid Quantum-Classical Neural Network (QNN) built with PennyLane and PyTorch. The pipeline features zero-leakage local data sanitization, parameterized variational quantum circuits with local observables to mitigate barren plateaus, and direct head-to-head performance evaluations against classical Multi-Layer Perceptrons (MLPs).
